ALI RIZA YILMAZ — PORTFOLIO SITE
================================

Contents
- index.html: responsive single-page portfolio (Turkish/English toggle)
- assets/ali-riza-yilmaz-vesikalik.png: supplied formal portrait
- assets/ali-riza-yilmaz-cv-tr.pdf: Turkish CV supplied by the user
- assets/ali-riza-yilmaz-cv-en.pdf: English CV supplied by the user

Publish with GitHub Pages
1. Download and extract this ZIP on your computer.
2. Open your GitHub repository: https://github.com/aliyilmazgh/aliyilmazgh.github.io
   (The repository must be named aliyilmazgh.github.io for the account's user site.)
3. On the repository Code tab, click Add file > Upload files.
4. Drag index.html and the assets folder from the extracted folder into the upload area.
   Upload the contents, not the ZIP itself and not an extra outer folder.
5. At the bottom, enter a commit message such as "Publish portfolio update" and click Commit changes.
6. Open Settings > Pages. Set Build and deployment to "Deploy from a branch", choose branch "main" and folder "/ (root)", then Save.
7. After GitHub Pages finishes deploying, visit https://aliyilmazgh.github.io/

Important
- If your repository still has a different name, rename it to aliyilmazgh.github.io first.
- Contact form opens the visitor's email application (mailto); it does not store or deliver messages through a server.
- This site is static and does not need npm, a build step, or paid hosting.
- Search engine indexing and rankings are not guaranteed. After publication, verify the URL in Google Search Console.
